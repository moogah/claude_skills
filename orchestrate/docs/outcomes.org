This file is the list of outcomes the =orchestrate= skill is supposed to result in. Each outcome is traced up to a north-star goal (=north-star.org= in the skills workspace) and down to the rules in the flows, roles and templates that produce it; the rules may be rewritten while the outcome holds. The evals are written against this list: a case names the outcome it covers, and an outcome with no case is marked as not covered. The file describes the skill text on the branch that carries it (here =skill-evals=, cut from installed =main= at =e9025c7=), so another branch carries its own list. Its terms (outcome, rule, step, case, interface artifact, rubric, eval agent, regression set, advisory set) are defined in =docs/glossary.org=. It was drafted from the evidence files E7 (the inventory of 216 statements, 39 of them at the outcome level) and E9 (the interface artifacts) of the research effort =research/skill-evals= in the skills workspace, with every quote checked against this tree, and was reviewed by the user on 2026-11-12, who accepted the 31 outcomes as written ("well stated enough for us to continue").

* How to read an entry

- The heading :: the id and the outcome, one sentence a user could check by looking at what a cycle produced or at what reached them. Ids are stable; the two letters are the part's code in E7 (NS the whole change as the north star states it, XC across the whole change as the skill text states it, DP the dispatcher, OP opening, DR the design round, PL plan, EX execute, IN integrate, IL the inline path).
- =GOAL= :: the north-star goal the outcome serves. A bare id means the outcome's source is that goal's own text; "(inferred)" means the skill text states the outcome and the link to the goal is the drafter's reading, since the skill text names no goal number; "none stated" means no goal says it.
- =OBSERVED_AT= :: the step, and the interface artifact, where the outcome shows, in the skill's names. "E9 row" is a row of E9 Table 1 (the 39 steps where work passes between agents).
- =SPANS= :: =one step= when the outcome can be seen in what one step wrote, given that step's input; =several steps= when it shows only across steps, phases or cycles (E7 Table 3, its C-numbers).
- =STATE_LAYER= :: whether the statements quoted under Source stand, as quoted, in the =state-layer= branch's text (=3502e7c=): =same=, =differs: <how>=, or =not checked=. Only the Source statements were compared; a rule that differs there is named in the Note where it was seen.
- =RECORD= :: the rows of E1 Table 3 (B1 to B13: what was fixed more than once, regressed or failed its measure) that concern this outcome, or =none=.
- =CASES= :: the cases that cover the outcome, or =none=. Five cases over four outcomes were picked 2026-11-12 by the selection rule (research brief, * Decided 2026-11-11) and were built at the hand edit the same day; each names its case in the skills workspace's =evals/cases/=.
- Source :: the statement the outcome is drawn from, quoted, with its file and section heading. Code in a quote is written as in org; bold is dropped.
- Rules :: the main rules that produce the outcome, quoted the same way. [O]: the source itself links the rule to the outcome (the rule states it, sits in the passage that states it, or points to it). [I]: the link is the drafter's inference.
- Note :: an ambiguity, two sources that disagree, or the E7 rows merged into the entry.

Copied from the skills repo, branch =skill-evals= at =b3012e5=, =orchestrate/docs/pages/= (2026-11-14; first built at =b0d3358= on 2026-11-13). It is the first spec page: the orchestrate skill's =execute= spec, proven by LLM eval cases, one run three times per tree and the rest by their single validation trial.

- =build.py= :: reads =docs/specs/<capability>.org=, the eval cases on that capability (=evals/cases/*/case.org= with =:CAPABILITY:=, their =expected.org= items and =:CITES:=), =evals/history.jsonl= (the latest counted run per tree, else the trial a case's =:VALIDATED: <commit> <run> t<n> (<tree>)= names), and each trial's =t<n>.details.json=, =t<n>.artifact.txt= and =t<n>.jsonl=. Writes =<capability>.data.js= and =<capability>.html=.
- =spec.template.html= :: the page. All layout, styles and script; no data.

What is specific to that workspace, and is replaced when adapting it:

- the paths: =SPECS=, =WORKTREE=, =EVALS=, and =TREES= (the trees a page shows, the one implementing the spec first);
- the results' format: history rows (=run_id=, =tree=, =trial=, =counts=, =rubric= with each item's =checks=, =checks=, =cites=, =versions=, =details=) and the details file (=checks= with =detail=, =rubric= with =reasons= and =quotes=, =audit= with =verdicts= and =reasons=). A check reaches a scenario through the rubric item it sits under (since 2026-11-14 a check cites none of its own);
- the end state's sections in =t<n>.artifact.txt=, which the case's =checks.py= writes: the change branch's log (subject, then body), the home's added or changed files in full (the journal in =state.json=, entries the fixture planted left out by date; asks as =inbox/ask-*.org=), agents spawned, and the calls the collector names as having run the tests. Artifacts from before 2026-11-14 have their own journal and ask sections and no test-call section, and the build reads both forms;
- the milestone kinds and their lanes, which are those of an orchestrate execute phase;
- the link from a milestone to a check, by matching the check's detail text (a heuristic: rule 6 of =SKILL.md=).
